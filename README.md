# ArylTerm

Android terminal client for connecting to tmux sessions on a server.

## Layout

- `lib/`, `android/`, `test/`: Flutter app scaffold
- `backend/`: Rust backend starter

## Environment

- Flutter 3.47.2 at `F:\android\flutter`
- Dart 3.13.2
- Rust 1.95.0
- Cargo 1.95.0
- Android SDK 35.0.1
